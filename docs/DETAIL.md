# 语音输入·说完即发

在输入框左侧加一个说话按钮，把一段话转成文字填进草稿；打开「自动发送」后，识别完直接发出去。

## 用法

1. 点一下 `说话` 开始录音，按钮变成红色 `停止`，右侧显示秒数。
2. 再点一下结束，转写结果写入草稿。
3. 点 `自动发送` 开启后，识别完直接提交；关闭时只填草稿，由你按 Enter 发送。
4. 录音达到识别服务公布的上限时会自动停止。

## 行为

- 识别走宿主已有的语音服务（`speech` Remote → `ctx.speechToText`），录音被转成 16 kHz 单声道 PCM16 WAV 后提交；音频不落盘、不进会话。
- 转写结果先过一张术语表（`DeepSeek` / `lint` / `commit` / `build` 等常见误识别）。
- **高危词**（删除、推送、发布、覆盖、强推、`rm`、`force push` 等）命中时，即使开着自动发送也只写入草稿，不发送。
- 自动发送开关的状态保存在浏览器本地，换设备不跟随。

## 限制

- 需要麦克风权限，且页面必须是 `https` 或 `127.0.0.1` 这类安全上下文。
- 识别引擎需要已启用（宿主的语音输入包）；未就绪时按钮会提示"语音引擎未就绪"。
- 一次录音受识别服务公布的时长与字节上限约束。
- 不支持常开麦克风、唤醒词、流式字幕。
