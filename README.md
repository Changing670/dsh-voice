# dsh-voice

给 [DeepSeek Harness](https://github.com/deepseek-ai/deepseek-harness) 加一个说话按钮：录一段话，转成文字填进草稿，可选直接发出去。

**不联网、不下载模型、不训练、不改识别器**——它只是把宿主已有的语音识别接到输入框上，再做一层术语纠正。

## 它能做什么

- 输入框左侧一个 `● 说话` 按钮：点一下开始录，再点一下结束。
- 转写结果先过术语表，再写进草稿：`deep sick` → `DeepSeek`、`林特` → `lint`、`康密特` → `commit`。
- `自动发送` 开着时，说完直接提交；关着时只填草稿，你按 Enter。
- 命中高危词（删除 / 推送 / 发布 / 覆盖 / 强推 / `rm` / `force push`）时，**即使开着自动发送也只填不发**。
- 内置 36 个规范词、约 90 个别名，覆盖中英混说里最常被听错的那批。

## 依赖

宿主自带的语音输入包（SenseVoice，本地 CPU 推理）。在 **插件** 页里确认 `@deepseek-ai/dsh-experimental-voice-input-bundle` 已启用；首次使用会下载约 239 MB 模型。

## 安装

在 **插件 → 添加插件** 里填：

```
github:Changing670/dsh-voice
```

或者把本仓库克隆到本地，用「添加本地目录」指向它。装完刷新页面。

## 用法

1. 点 `说话` → 允许麦克风 → 说一句 → 再点一次。
2. 文字进草稿后可以改，改完按 Enter。
3. 想要"说完即发"，点一下 `自动发送`（变蓝即开启）。

## 已知限制

- 术语表是通用默认值，你的专有名词需要自己补（改 `client.js` 里的 `TERMS`）。
- 一次录音受识别服务限制（默认最长 120 秒，插件内限制 60 秒）。
- 麦克风需要 `https` 或 `127.0.0.1`，且浏览器要有权限。
- 只在 Web 界面可用。

## 卸载

插件页停用即可，草稿、设置、录音都不残留。
